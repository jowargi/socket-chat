# Простой чат на сокетах (Python)

Проект представляет собой минималистичный консольный клиент-серверный чат, реализованный на чистом Python с использованием модуля `socket`. Позволяет устанавливать TCP-соединение между сервером и одним клиентом, обмениваться текстовыми сообщениями в реальном времени и корректно завершать сеанс.

## Основные возможности

- **TCP-соединение**: Установка стабильного соединения между клиентом и сервером.
- **Поочерёдный обмен сообщениями**: Клиент и сервер отправляют сообщения по очереди.
- **Корректное завершение**: Любая из сторон может инициировать разрыв соединения, отправив команду `/quit`.
- **Кодировка UTF-8**: Поддержка кириллицы и других символов.
- **Утилита для приёма данных**: Реализована функция `receive()` для сборки сообщений из потоковых чанков.

## Принцип работы

1. Сервер запускается и ожидает подключения на `localhost:8080`.
2. Клиент подключается к серверу.
3. Диалог происходит в режиме "запрос-ответ": после отправки сообщения сторона ожидает ответ.
4. Сеанс завершается, когда любая из сторон отправляет команду `/quit`.

Проект предназначен для демонстрации основ сетевого программирования на Python и может служить основой для более сложных многопользовательских или многопоточных чатов.
